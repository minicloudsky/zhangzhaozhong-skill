# Zhang Zhaozhong Perspective Skill

# 张召忠（局座）· 思维框架 Skill

> 用局座的眼睛看世界——一个可运行的军事分析思维操作系统。

## 这是什么？

这是一个为 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 设计的人物思维框架 Skill。激活后，AI 会以张召忠（局座）的思维方式、分析框架和表达风格来回应你的问题。

**它不是模仿秀**——不是拼凑张召忠说过的话，而是提炼他 **怎么思考**（HOW he thinks），让你能用他的视角审视军事、地缘政治和国防问题。

## 核心内容

| 维度 | 数量 | 说明 |
|------|------|------|
| 心智模型 | 5 个 | 海权决定论、技术代差决定论、历史镜像思维、科普即国防、以实力求和平 |
| 决策启发式 | 8 条 | "如果X，则Y"的快速判断规则，每条有案例支撑 |
| 表达 DNA | 完整 | 句式指纹、高频词汇、幽默方式、确定性表达模式 |
| 内在张力 | 3 对 | 技术vs人、严谨vs娱乐、和平vs强硬 |
| 诚实边界 | 6 条 | 明确标注这个 Skill 做不到什么 |
| 示例对话 | 2 组 | 含非军事问题的降级示范 |

## 快速开始

### 安装

将 `zhang-zhaozhong-perspective` 目录复制到你的 Claude Code skills 目录：

```bash
# 克隆仓库
git clone https://github.com/minicloudsky/zhangzhaozhong-skill.git

# 复制到 Claude Code skills 目录
cp -r zhangzhaozhong-skill ~/.claude/skills/
```

### 使用

在 Claude Code 对话中，用以下任意方式激活：

```
局座怎么看俄乌冲突的最新走势？
用张召忠的视角分析一下南海局势
局座分析一下印度海军的实力
```

退出角色：说「退出」「切回正常」即可。

## Skill 工作原理

```
用户提问
   ↓
Step 1: 问题分类（需要事实 / 纯框架 / 混合）
   ↓
Step 2: 局座式研究（按问题类型选择研究维度）
   ↓
Step 3: 局座式回答（心智模型 + 表达 DNA）
```

- **需要事实的问题**（如"中国航母战力如何"）→ 先用工具搜索最新信息，再用局座框架分析
- **纯框架问题**（如"为什么要重视海权"）→ 直接用心智模型回答
- **超出范围的问题**（如"股市怎么看"）→ 局座式降级："这个你得问经济学家，我就是个当兵的"

## 适用场景

- 分析国际军事冲突和地缘政治
- 评估武器装备和军事技术发展
- 理解海权战略和海洋安全
- 用通俗语言理解复杂军事概念
- 从军事视角审视科技发展

## 局限性

> 这个 Skill 是一面镜子，不是水晶球。

- 基于公开信息提炼，无法还原涉密判断
- 海军/海洋视角偏重，陆军/空军/火箭军分析深度不足
- 擅长战略方向判断，短期事件预测经常有偏差
- 调研截止 2025 年 5 月，之后的变化未覆盖
- 不能替代真正的军事分析，涉及真实决策请咨询专业机构

## 关于张召忠

张召忠（1952-），海军少将（退役），国防大学教授。中国最知名的军事评论员之一，曾长期担任央视《防务新观察》《今日关注》等节目军事评论员。2015 年退休后入驻 B 站（账号"局座召忠"），成为现象级军事科普 UP 主。网友称其为"局座"（源自"战略忽悠局局长"的网络梗）。

代表著作：《走向深蓝》《百年航母》《谁在包围中国》《进击的局座：悄悄话》等。
